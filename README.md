# BoncyPlatform 

The Godot game is in the folder "game"

it's a 3 level 2/3d Platformer. the characters are realy bouncy objects such as a slimeball, hellohitty and a dounut.

the mission is to contiune and jump up and up.

## controls
a , arrow-left:  move left
d , arrow-right: move right
w,  arrow-up: move forward
s, arrow-down: move back
